# AutoDisenchant

**AutoDisenchant (AutoDE)** — аддон для быстрого и **безопасного** распыления зелёных (необычных) предметов в WoW Sirus 3.3.5a. Работает через *защищённую кнопку* (`SecureActionButtonTemplate`), адаптируясь под правила Blizzard — без ошибок «Модификация заблокирована». Каждый клик по кнопке распыляет текущий зелёный предмет и мгновенно готовит макрос на следующий. Авто-подбор пыли из лут-окна — средствами самого клиента.

## Как это работает

```
клик (ты) → распыляется текущий предмет → PostClick:
  предмет убирается из списка → макрос следующего предмета
  подставляется в ТУ ЖЕ кнопку → снова клик → ... → и т.д.
```

- Аддон **никогда** не кликает из Lua-кода (ни таймеры, ни `OnUpdate`) — кнопка нажимается только Вами
- Авто-подбор пыли — через клиентский авточат (`autoLootDefault`), аддон не трогает лут-окно из Lua
- Пока окно аддона открыто — авточастичный лут включён ради мгновенного подхвата пыли; при закрытии возвращает Ваше значение

## Фильтр предметов

- Качество: только **зелёные** (uncommon)
- Уровень предмета (`ItemLevel`) > 0
- Пропускает квестовые предметы (`quest` в ссылке)
- Проверяет наличие заклинания «Распыление»

## Установка

1. Скачайте/склонируйте репозиторий
2. Папку `AutoDisenchant` скопируйте в `Interface\AddOns\`
3. Перезагрузите игру или зайдите на персонажа

## Использование

1. Изучите профессию **«Наложение чар»** — у вас должно быть заклинание **«Распыление»**
2. Введите `/autode` — откроется окно
3. Нажмите **«Обновить список»** — отфильтрует подходящие зелёные предметы
4. Кнопка **«Распылить»** уже готова с макросом на первый предмет
5. **Кликните по кнопке «Распылить» мышкой** — предмет распылится, пыль заберётся автоматически
6. Сразу после клика аддон подготовит следующий предмет — просто продолжайте кликать ту же кнопку

## Команды

| Команда | Описание |
|---|---|
| `/autode` | открыть/закрыть окно |
| `/adisen` | то же (алиас) |
| `/disen` | то же (алиас) |
